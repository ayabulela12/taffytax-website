# Tafy Tax — Website Redesign

## Live Site
🔗 [tafytax.com](https://tafytax.com)

## Overview
Redesigned the Tafy Tax website to transform a cluttered, information-heavy site into a clean, modern experience. The client wanted a fresher look that felt approachable and easy to navigate without losing important content.

## My Role
Frontend Developer — responsible for the full redesign and rebuild.

## What I Did
- Audited the existing site and identified UX pain points
- Restructured the information architecture to reduce cognitive load
- Designed and implemented a clean, modern UI
- Rebuilt the entire site from scratch using Next.js
- Ensured full responsiveness across mobile, tablet and desktop

## Tech Stack
| Technology | Purpose |
|---|---|
| Next.js | Frontend framework |
| React | UI components |
| CSS Modules | Styling |
| Vercel | Deployment |

## Challenges & Solutions

**Solution:** Broke content into digestible sections with clear headings, icons and whitespace.
